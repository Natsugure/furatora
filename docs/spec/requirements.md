# 要件: 駅ページ・路線の駅一覧ページのタイトルに駅名・路線名を出す (Issue #8)

## 概要

- **対象**: `apps/web` の `layout.tsx`・駅ページ（`/stations/[slug]`）・路線の駅一覧ページ（`/lines/[slug]/stations`）
- **参照**: [design.md](./design.md) / [tasks.md](./tasks.md) / [Issue #8](https://github.com/Natsugure/furatora/issues/8) /
  [station-visibility.md](../domain/station-visibility.md)
- **信頼度**: 92%（高）。触るのは画面の2ページと layout だけで、DB は変えない

## 背景

いまタイトルを決めているのは `layout.tsx` の固定の `metadata` だけなので、どのページのタブも
「ふらっと乗換 | バリアフリー駅・列車案内」になる。複数のタブで開いたときや、ブックマーク・履歴・共有したリンクで、
どの駅・路線のページか見分けられない。

## 要件（EARS）

- **REQ-1** 駅ページを表示したとき、システムはタイトルを `<駅名>駅 <路線名> | ふらっと乗換` にすること
  （例: `渋谷駅 東京メトロ銀座線 | ふらっと乗換`）
  - **REQ-1.1** 駅名が「駅」で終わる場合、システムは「駅」を足さないこと
  - **REQ-1.2** 駅が複数の路線を持つ場合、システムは重複を除いた路線名を「、」でつないで出すこと
  - **REQ-1.3** 駅が路線を1つも持たない場合、システムは `<駅名>駅` だけを出すこと
- **REQ-2** 路線の駅一覧ページを表示したとき、システムはタイトルを `<路線名>の駅一覧 | ふらっと乗換` にすること
- **REQ-3** 駅・路線が見つからない、または未公開の場合、システムはタイトルを `ページが見つかりません | ふらっと乗換` にし、
  駅名・路線名を出さないこと
- **REQ-4** トップページを表示したとき、システムはタイトルを今と同じ `ふらっと乗換 | バリアフリー駅・列車案内` にすること
- **REQ-5** 1回のリクエストで、システムは本体の描画とタイトルの組み立てに同じ読み取り結果を使い、DB を2回読まないこと

## 対象外

- `notFound()` が HTTP 200 を返す問題（#70）
- `description` や OGP などのタイトル以外のメタデータ
