# ADR-0019: アプリアイコンを「正面の電車＋平らな線＋ふらっと」にし、小さいサイズでは文字を外す

- **ステータス**: Proposed
- **日付**: 2026-10-18
- **決定者**: @Natsugure
- **関連**: [ADR-0017](./0017-soft-rose-palette-and-typography.md)（配色）, GitHub Issue #166,
  [見本](./assets/0017/06-app-icon.png)

---

## コンテキストと課題

これまでのアイコンは、ローズの地に、ゴールドの電車（上）と、白の車いすの人・ベビーカーを押す大人・子ども（下）を並べたものだった。

- 要素が6つあり、32px 以下では子ども・車輪・窓がつぶれる
- ひし形のパンタグラフと離れた車輪で、路面電車に見えやすい
- 電車と人の関係が描かれておらず、「乗れる」「乗り換えられる」が伝わらない
- ゴールドはローズとのコントラスト比が 2.18:1 で、白（3.69:1）より沈む。ブランドに3色目が増える

アプリ名は将来「ふらっと乗換」に変える予定である（本 ADR の範囲外）。

## 決定

- **図柄**: 上に正面から見た電車、まん中に段差のない平らな線、下にひらがなの「ふらっと」
  - 電車の脚が平らな線の上に立つ。「段差のない所を移動できる」を表す
- **色**: 地はローズ 500（`#DF5286`）、図柄と文字は白の2色。ゴールドは使わない
- **小さいサイズ**: 文字は 60px 程度までしか読めない。32px 以下（ファビコンなど）は、文字を外して電車と線だけを拡大した版を使う
- **書き出し**: 角を丸めない正方形で書き出す。角丸は OS が付ける。文字はアウトライン化する

## 却下した選択肢

### 今の構図を単純にする（電車の線画＋車いす＋ベビーカー）

- **却下理由**: 要素を減らしても、電車と人の関係が描かれない点は残る

### 開いた電車のドアの前に、車いすとベビーカーを置く

- **良い点**: 「どのドアから乗れるか」というアプリの中身と結び付く
- **却下理由**: ドアの中に2人を入れると、32px 以下でつぶれる。開発者の評価で、配置がしっくり来なかった

### 駅番号の丸の中に、車いすとベビーカーを置く

- **却下理由**: 電車が描かれず、何のアプリか伝わりにくい

### 人を描かない抽象的な形（乗換駅の丸を車輪に見立てる、路線と ▲▼、「ふ」の字を路線図で書く）

- **良い点**: 小さいサイズに強い
- **却下理由**: 意味が伝わるまでに一拍かかる。開発者の評価で、しっくり来なかった

### 横向きの電車

- **却下理由**: 正面形のほうが駅の案内サインの電車マークに近く、脚が平らな線に立つ形が作れる

### 文字を「ふらとら」（現在のアプリ名）にする

- **却下理由**: アプリ名を「ふらっと乗換」に変える予定のため

## 影響

- `apps/web/src/app/icon.svg`・`apple-icon.png`・`favicon.ico`・`public/icons/android-chrome-*.png` を差し替える
- 本番用のデータは、ベクター編集ツールでの清書（線の太さ・字形の調整・文字のアウトライン化）が要る
- アプリ名の変更までは、アイコンの文字（ふらっと）と画面上のアプリ名（ふらとら）が食い違う

## レビュー

次のいずれかが起きたら再評価する。

- アプリ名の変更を取りやめた
- ストアや OS の審査・ガイドラインで、文字入りのアイコンが問題になった
