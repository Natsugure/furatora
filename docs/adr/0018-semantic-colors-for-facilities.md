# ADR-0018: フリースペース・優先席・出口・移動手段・状態の意味色を決め、出口を駅サインの黄からバター色に変える

- **ステータス**: Accepted（決定1 のフリースペースの一部編成と、乗換のプレートの枠は [ADR-0024](./0024-free-space-ring-and-transfer-plate-edge.md) で置き換え）
- **日付**: 2026-10-18
- **決定者**: @Natsugure
- **関連**: [ADR-0017](./0017-soft-rose-palette-and-typography.md)（配色の土台）,
  [ADR-0010](./0010-platform-diagram-package-edit-layer.md)（ホーム図パッケージ）,
  GitHub Issue #166, [見本](./assets/0017/README.md)（ホーム図: `05-platform.png`、駅の詳細: `04-station-*.png`）

## コンテキストと課題

ホーム図と駅の画面では、色が意味を持つ。これまでは次のとおりだった。

| 意味 | これまでの色 |
|---|---|
| フリースペース | 青（`#4072B3`） |
| 優先席（カード） | オレンジ系（`#FFB300` など） |
| 出口のプレート | 駅サインの黄（`#FFD400`、黒文字、輪郭 `#C99A00`） |

出口の黄は「実際の駅サインの語彙に合わせる」という理由で選ばれていた（`globals.css` のコメント）。

配色を Soft Rose にする（ADR-0017）にあたり、次の点を決める必要がある。

- 青のフリースペースは、ローズ基調の中で浮く
- 駅サインの黄（`#FFD400`）は彩度が高く、やわらかい配色の中で強く目立つ
- 色の数が増えると、色覚の多様性によって見分けにくい組が生まれる

## 決定

### 決定1: 意味色の割り当て

| 意味 | 色 | 補足 |
|---|---|---|
| フリースペース | ブランドのローズ（500 `#DF5286`、一部編成は 300 `#EE9FBA`、その中の記号は 800 `#6E2140`） | アプリの主役の情報なので、ブランド色を当てる。一部編成を 200 にすると、号車の地（1.26:1）や通常のドアの印と見分けにくい |
| 優先席 | 朱色（50 `#FCEEE8` / 200 `#F4C3B1` / 500 `#D9481C` / 700 `#A3361A`） | 決定2 |
| 出口 | バター色（100 `#FBF3D2` / 300 `#F0DC85` / 700 `#6B5A0E` / 900 `#4A3F0A`） | 決定3 |
| ベビーカー | ローズ | |
| 車いす | スレート（50 `#EEF3F8` / 500 `#5B7FA6` / 700 `#3F5F82`） | |
| 乗換: バリアフリールートあり | セージ（50 `#ECF5F0` / 500 `#4E9A7A` / 700 `#2F6E54`） | ◎ |
| 乗換: バリアフリールートなし | アンバー（50 `#FBF1E3` / 500 `#C98A1B` / 700 `#8E5A12`） | × |
| 乗換: 確認できていない（ADR-0012） | ニュートラル（`#F4EFF1` / `#7A6E72`） | ＊ |

乗換の状態の分類は `@furatora/transfer-difficulty/domain` の `assessRoutes` による。本 ADR は色だけを決める。

**色だけで意味を伝えない。** 乗換の状態には記号（◎ × ＊）と文言を、ホーム図の印には凡例を必ず付ける。

### 決定2: 優先席は、車内の人型ピクトグラムの朱色（`#D41D00`）を、やわらげた `#D9481C` にする

車内の吊り革や案内表示の人型ピクトグラムで使われる色（RGB 0.830 / 0.112 / 0.000 = `#D41D00`）を出発点にする。
そのままでは路線色とぶつかるため、わずかに橙へ寄せ、明るさを上げた `#D9481C` にする。

実測（ΔE は CIELAB の ΔE76。「通常／1型色覚の模擬／2型色覚の模擬」の順。模擬は Machado 2009）。

| 組 | ΔE |
|---|---|
| `#D9481C` と フリースペース（`#DF5286`） | 54 / 57 / 51 |
| `#D9481C` と 出口（`#F0DC85`） | 70 / 43 / 35 |
| `#D9481C` と 丸ノ内線（`#E60012`） | 20 / 8 / 2 |
| （参考）`#D41D00` と 丸ノ内線 | 9 / 3 / 4 |

- 白地とのコントラスト比は 4.29:1（図形の基準 3:1 を満たす）。文字は 700（`#A3361A`、50 の地で 5.98:1）を使う
- **丸ノ内線などの赤い路線色とは、色覚によっては見分けられない。** 同じ図の中では、優先席の印を四角、路線色を丸や線として形で分け、凡例を付ける

### 決定3: 出口は駅サインの黄（`#FFD400`）をやめ、バター色にする

- 出口のプレートの地は 300（`#F0DC85`）、文字は 900（`#4A3F0A`、7.62:1）
- 画面上の小さな出口のタグは、地 100（`#FBF3D2`）、文字 700（`#6B5A0E`、6.09:1）
- 「黄色系」であれば出口として読めると判断した。調和を優先する

## 却下した選択肢

### 出口に駅サインの黄（`#FFD400`）を残す

- **良い点**: 実際の駅サインと同じで、最も確実に出口と読める
- **却下理由**: 彩度が高く、ローズ基調の画面で最も強く目立つ要素になってしまう。黄色系であれば出口と読めるため、調和を優先した

### 出口にアプリアイコンの電車のゴールド（`#DFC752`）を使う

- **却下理由**: ブランドの色と出口の意味が結び付き、アイコンを変えたときに出口の色も揺れる。アイコンの色の見直し（ADR-0019）と切り離した

### 優先席に `#D41D00` をそのまま使う

- **良い点**: 車内のピクトグラムと同じ色になる
- **却下理由**: 丸ノ内線（`#E60012`）との ΔE が通常の見え方でも 9 しかなく、見分けられない

### 優先席に萌黄（`#AACF53`）を使う

一部の社局が、優先席の座席のモケットやステッカーに使っている色。

- **良い点**: 路線の赤とぶつからない
- **却下理由**:
  - 出口のバター色（`#F0DC85`）との ΔE が、2型色覚の模擬で 13 しかない。出口と取り違えうる
  - 白地とのコントラスト比が 1.79:1 で、白い車両の上の小さな印が見えにくい

### 優先席にスレート（車いすと同じ色）を使う

- **却下理由**: 1つの色に「車いす」と「優先席」の2つの意味が載る

### 「バリアフリールートなし」を赤のまま残す（現状 `#E53935`）

- **却下理由**: 丸ノ内線などの赤い路線色とぶつかる（ADR-0017）。「なし」は禁止ではなく注意を促す情報なので、アンバーで足りる

### 「確認できていない」に色を付ける

- **却下理由**: 情報が無いことを示す状態であり、良し悪しを示す色を付けると誤解を招く。現状どおりニュートラルにする

### フリースペースを青のまま残す

- **却下理由**: ローズ基調の中で、最も重要な情報が別系統の色になり、画面がまとまらない

## 影響

- `packages/platform-diagram/src/styles.css` と `apps/web/src/app/globals.css` の、フリースペース・優先席・出口のトークンの値が変わる
- **Admin のホーム図の見た目も変わる。** Admin は同じパッケージのトークンを読み込むため（ADR-0010）
- 出口のプレートは、地の色だけでは白地から浮きにくい（白地とのコントラスト比 1.37:1）。そのため輪郭を 700（白地 6.79:1）にして浮かせる。乗換のプレート（白地に黒い輪郭）とは、地の色と文言で見分ける
- 出口のプレートの補足の文字（11px）は透過させない。900 を 300 の地に 75% で重ねると 4.16:1 で、本文の基準（4.5:1）を割る
- `globals.css` の「出口は黄地に黒」というコメントは、本 ADR を参照する内容に書き換える

## レビュー

次のいずれかが起きたら再評価する。

- 利用者から、出口が見つけにくいという声があった
- ホーム図に路線色の要素が増え、優先席の印と並ぶようになった
- 優先席の位置をホーム図に描くようになった（印の形と色の組み合わせを確かめ直す）
