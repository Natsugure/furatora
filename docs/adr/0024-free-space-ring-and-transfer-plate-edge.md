# ADR-0024: ホーム図の一部編成のフリースペースを同じローズの輪にし、乗換のプレートの枠を neutral-500 にする

- **ステータス**: Accepted
- **日付**: 2026-10-23
- **決定者**: @Natsugure
- **関連**: [ADR-0018](./0018-semantic-colors-for-facilities.md)（決定1 のうち「一部編成は 300、その中の記号は 800」と、「影響」の「乗換のプレート（白地に黒い輪郭）」を置き換える）,
  [ADR-0017](./0017-soft-rose-palette-and-typography.md)（見本: `assets/0017/source/Platform.dc.html`）,
  GitHub Issue #174

---

## コンテキストと課題

Issue #174 で、横のホーム図に ADR-0017 の見本の見た目を当てる（PR3a）。
見本では、フリースペースの印がドアの位置で号車のホーム側の縁に乗り、全編成は塗った丸、一部編成は輪で描かれている。

これまでの印は号車の中に置いた丸で、ADR-0018 決定1 により次のとおりだった。

| 印 | 地 | 中の記号 |
|---|---|---|
| 全編成 | 500 `#DF5286` | 人の記号 |
| 一部編成 | 300 `#EE9FBA` | 人の記号（800 `#6E2140`） |

2つの印は**形が同じで、色の明るさだけが違う**。ADR-0018 決定1 の「色だけで意味を伝えない」に沿っていない。

乗換のプレートの枠は黒（`#111111`）で、ADR-0018 の「影響」も「乗換のプレート（白地に黒い輪郭）」を前提にしている。
見本の枠は `#EBE4E7` 1.5px である。

### 実測（WCAG のコントラスト比）

印はホーム側の縁をまたぎ、白い縁（`--color-bg-card`）の上に載る。号車の地は `#EFE8EB`。

| 組 | 比 |
|---|---|
| 500 `#DF5286` と 白 | 3.69:1 |
| 500 `#DF5286` と 号車の地 | 3.06:1 |
| 300 `#EE9FBA` と 白 | 2.04:1 |
| 300 `#EE9FBA` と 号車の地 | 1.69:1 |
| 300 `#EE9FBA` と 500 `#DF5286` | 1.81:1 |
| neutral-500 `#7A6E72` と 白 | 4.88:1 |
| 黒 `#111111` と 白 | 18.88:1 |
| 見本の枠 `#EBE4E7` と 白 | 1.25:1 |

## 決定

1. **フリースペースの印は、全編成を 500 の塗った丸、一部編成を 500 の輪にする。** 色ではなく形で分ける。
   中の人の記号は描かない（見本どおり）。何の印かは凡例と `<title>`（「◯号車 ◯番ドア付近のフリースペース（一部編成）」）が伝える
2. **ADR-0018 決定1 の一部編成の 300 と、記号の 800 は使わない。** トークン `--color-free-nonstandard`・`--color-free-standard-text`・
   `--color-free-nonstandard-text` を消す
3. **乗換のプレートの枠を neutral-500（`#7A6E72`、白地 4.88:1）にする。** 号車の枠（`--color-train-car-border`）と同じ色

## 却下した選択肢

### 一部編成を 300 の塗りに 800 の記号のまま残す（ADR-0018 決定1）

- **良い点**: 今の決定を変えずに済む
- **却下理由**:
  - 全編成と形が同じで、明るさの差（1.81:1）だけで見分けることになる。色だけで意味を伝えないという約束に反する
  - 300 は白地で 2.04:1、号車の地で 1.69:1 しかなく、図形の基準（3:1）に届かない

### 一部編成を 300 の輪にする

- **却下理由**: 形では分けられるが、輪の線が 300 では白地で 2.04:1 しかなく、細い線がさらに見えにくくなる。500 の輪なら白地で 3.69:1

### 乗換のプレートの枠を黒（`#111111`）のまま残す

- **良い点**: 白地から最も強く浮く（18.88:1）
- **却下理由**: ローズ基調の画面で、純黒の枠だけが強く目立つ。プレートの文字も純黒ではなく `--color-text-primary` を使っている（ADR-0017 決定2）

### 乗換のプレートの枠を見本の `#EBE4E7` にする

- **却下理由**: 白地との比が 1.25:1 で、白地の画面の上でプレートの外形が分からない

## 影響

- 号車の外に印を置くため、印の白い縁がホーム側の要素（ホーム帯・対面乗換のティント・両端の距離ラベル）にかかりうる。
  重なりの扱いは図の幾何の問題として `geometry.ts` の定数と `DiagramSvg` で扱う
- `docs/domain/design-system.md` の「フリースペース」の行と、`docs/domain/platform-coordinate-system.md` のプレートの記述は、本 ADR を参照する
- ADR-0018 の決定2（優先席）・決定3（出口）と、決定1 の残りの行は変わらない

## 再評価の条件

- 利用者から、一部編成の輪が全編成の丸と見分けにくい、あるいは見落とすという声があった
- 図の縮尺（`PX_PER_METER`）を下げ、輪の線が 1px 前後まで細くなった
- 乗換のプレートが出口のプレートや号車と見分けにくいという声があった
